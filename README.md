# 初中电学实验室

在浏览器中打开 `index.html`，或使用仓库部署的网页。离线使用时，请把 `index.html`、`classroom.js`、`classroom.css`、`devices.js`、`interface.js`、`interface.css` 放在同一个文件夹。

## 典型实验

实验菜单按“规律探究、控制电路、测量实验”分组，包含 13 个预设：

| 分组 | 实验 |
| --- | --- |
| 规律探究 | 串联电流、并联电流、串联电压、并联电压、电流与电压的关系、电流与电阻的关系 |
| 控制电路 | 变阻器调亮度、串联开关作用、并联开关控制、变阻器 A-C / B-C 接法对比 |
| 测量实验 | 伏安法测电阻、测量小灯泡电功率、探究小灯泡灯丝电阻的变化 |

串联电流实验同时使用三个电流表；电压规律实验同时使用三个电压表。并联电压表分别位于被测对象上方，接法对比保留变阻器指定接线柱。电路图已接好，切换实物图后可按参考图自行接线；开关作用实验可以逐个断开开关对比。测量实验初始开关断开、变阻器接入最大阻值。

原有灯泡实验继续采用固定电阻近似；新增“探究小灯泡灯丝电阻的变化”使用非线性稳态灯丝模型。灯泡属性中可切换模型，亮度由实际功率决定。

## 课堂工具

- **全屏**：进入大屏演示；点击按钮或按 Esc 退出。画布随窗口尺寸适配。
- **导出实验 / 导入实验**：下载实验 JSON 文件，支持实验命名与北京时间精确到分钟的文件名；导入后自动完整显示电路。保存两个视图的布局、接线柱、参数、参考电路、课堂模式和记录。打开文件前先校验，失败时保留当前实验；打开成功后可用“撤销”恢复原实验。
- **放大读表**：选择任一电流表或电压表，放大查看当前量程、刻度和指针。表盘刻度加深加长、数字增大。
- **两行操作栏**：第一行保留实验、选择、导线、撤销、视图、整理、完整显示和全屏；第二行保留文件、放大读表、实验记录、课堂、显示、元件库、属性和保存状态。低频操作在菜单中，旋转和删除放在选中对象的属性中。
- **开关与选中**：单击或轻点开关手柄切换通断，拖动手柄不会切换；双击底座打开操作卡片。其他元件双击主体打开卡片，保留当前工具；正在连线时不会打开卡片或取消临时导线。接线柱只用于连线。
- **元件命名**：同类只有一个时使用 A、V、L、R、S、M、D、电源、电铃，多个时按创建顺序编号；电阻与变阻器共用 R 序列。增删自动更新，移动和旋转保持编号；属性中支持手动命名及恢复自动命名，实验文件保存命名方式。
- **变阻器原理**：选中变阻器后在属性中打开，课堂菜单不再提供重复入口。元件库与画布使用固定端引线、上方折线滑片引线的统一符号。
- **屏幕适配**：元件库与属性面板均可收起，小屏工具栏横向滚动；参考电路图标题可折叠。高分屏画布按像素比绘制，“完整显示电路”重新适配当前画布。
- **导线三控制点**：选择导线后始终显示3个橙色编辑控制点，拖动可改变走向；平滑采样点与内部避障路径不直接作为编辑点。电路图、实物图分别保存编辑状态，撤销、自动保存和实验JSON导入导出均可恢复。
- **移动时保持布线**：拖动器材时导线端点实时跟随，手调控制点保持原位，只预览相关线路，不重新求解电学状态或全局寻路。松开后检查相关导线的碰撞；普通导线优先局部修正，手动编辑的导线保留控制点并提示冲突。新增实物导线优先局部寻路，整体整理仍可重新布局。
- **自动保存**：在当前浏览器保存实验。重新打开时选择“恢复上次实验”或“使用当前实验”；未作选择时，不覆盖上次缓存。跨电脑使用请下载实验文件。
- **导出图片**：导出当前视图的完整高清 PNG，保留明暗主题，去除网格、选中框和编辑接线柱提示。预测尚未揭示时，图片也会遮住结果。
- **实验记录**：选择 U、I 的测量对象，记录当前值、全部电表读数和滑片位置，导出 CSV 和 U-I 散点图。调节电源或滑片后返回记录窗口，继续采样。更换负载、接线或测量对象后单独分组；电源短路或所选电表超量程时拒绝记录。
- **课堂预测**：输入预测问题并隐藏结果；数字、指针、电流路径、灯泡亮度同步遮挡。点击“课堂”菜单的“揭示结果”查看当前参数的计算结果。
- **元件操作与故障**：双击主体打开简洁卡片，可删除、恢复正常或进入更多设置。灯泡、定值电阻、滑动变阻器、电流表、电压表、LED、电动机、电铃支持断路和短路；变阻器还支持同接上/下接线柱，电表支持正负接线柱接反。开关、电源和导线不设故障。全电路仅保留一处异常，更换位置会自动恢复上一处，整次操作可一次撤销。故障运行时立即生效，暂停时保存状态；恢复错误接法会还原原接线和手动路径。空白处、Esc、视图或工具切换关闭卡片；拖动、单击和接线操作不会弹出卡片。

清空电路或切换内置实验会开始新的记录；需要保留上一实验时，请先下载 JSON 或 CSV。

## 电流动画

箭头表示常规电流方向，采用统一间距和速度，不用疏密表示电流大小。电路求解给出有符号支路电流；实物导线各自按完整曲线累计长度排列，交叠的不同导线不抵消箭头；电路图共用导线合并后沿连续路径累计长度排列。箭头间距为24个画布坐标单位，采样点和连续线段中的微小电流差异不重新起算。变阻器定义左段 A→P 为正、右段 P→B 为正，P→金属杆电流为左右段电流之差，实物图、电路图和原理图共用该方向逻辑。

理想导线组成闭环时，各导线电流分配无法唯一确定；程序保留用电器读数，隐藏该连接网的导线及相关变阻器内部箭头，并提示原因。

## 新增教学负载

元件库的“发光、动力与声音”中可加入发光二极管、电动机／风扇和电铃，实物与符号均采用可随主题调整的 SVG。它们支持旋转、接线、布局转换、实验 JSON、撤销和高清图片导出。

- 发光二极管：实物长脚 A 为阳极、短脚 K 为阴极；符号从三角形一侧接阳极、竖线一侧接阴极。采用分段线性模型 `I=max(0,(Va−Vk−Vf)/Rd)`，默认正向压降 1.8 V、动态电阻 10 Ω、额定电流 20 mA。请串联限流电阻，超过额定电流会提示过载；不模拟击穿或永久损坏。
- 电动机／风扇：默认等效电阻 20 Ω、额定电流 0.15 A。扇叶平滑启动、惯性停转，电源反接改变转向；转速仅为示意，不模拟反电动势或轴负载变化。
- 电铃：默认等效电阻 30 Ω、额定电流 0.1 A，采用平均负载近似；不模拟内部断续触点的瞬时电流。符号下方两个引脚分别接线，不能把引脚末端用导线短接。达到动作电流时撞锤往复运动；点击“电铃声音”可开关声音，默认静音。声音为合成示意。
- 小灯泡：继续采用固定电阻近似，以实际功率驱动连续的灯丝颜色、玻璃暖色和光晕，约 0.1 秒的平滑响应；额定功率后仍能继续变化并提示过载。

安装 Playwright 及 Chromium 后，可运行 `node tests/browser-interface.cjs` 检查菜单、实际鼠标和触屏输入、命名、恢复弹窗、文件传输及屏幕适配。可用 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`、`CHROMIUM_LIBS` 指定已有运行环境；`SCREENSHOT_DIR` 用于保存检查截图。

完整检查与本次回归修复见 [代码检查记录](docs/code-review-2026-10-21.md)。

### 曲线出线与采样

新增实物导线先尝试朝目标的自然曲线，再尝试安全的斜向或侧向引出；固定向上、向下的出线仅作为避障回退，避免接线柱附近先伸出再急回头。自动线路的存储点使用单调三次插值平滑，防止新的端点过冲。

曲线完成平滑后，再沿最终弧长等距生成显示采样点，通常约2个画布单位一个点；超长线路设有采样数量上限，但同一根线内仍等弧长分布。显示采样、49点编辑骨架和3个手动控制点相互独立，控制点不会被显示采样移动。重复绘制复用采样缓存。

旧实验文件保存的线路仍保留；需要让旧自动线路采用新的自然走线时，点击一次“整理实物线路”。手动控制点和保存恢复规则继续保留。

### 多电路布局与后台寻路

切换视图、整理线路和自动路径缓存失效后的复杂寻路在 Web Worker 中执行。按元件之间的外部导线连接拆分独立电路；开关断开不会将同一套电路拆开。每组独立优化端子、布局和线路，随后按包含元件与导线的完整范围留出间距摆放。独立电路已有摆放的自动重寻路仍将其他电路的元件作为障碍物。

计算期间画布提示“正在整理线路”，可以继续缩放、平移或切换视图；尚未完成的自动线路暂不绘制，已有手动线路仍按其保存形状显示。新的切换、整理、撤销和编辑会终止旧任务，结果应用前还会再次校验输入，避免旧任务覆盖新位置或连接。Worker 只回写布局和路径，不覆盖开关状态、电表读数及实时电流。任务超过30秒会停止，可重新点击整理线路重试。Blob Worker 不需要额外下载脚本，可用于本地打开的 HTML。

新增 `node tests/routing-regression.cjs` 使用真实后台线程验证多组摆放、主线程响应、取消、过时结果丢弃、读数与手动形状保留。`node tests/browser-routing.cjs` 在 Chromium 中分别验证 HTTP 与本地文件打开、三电路转换及快速切换；与现有浏览器检查一起运行。

### 新增的三个电学探究

- ⑪ 电流与电压：3 V 电源、10 Ω 定值电阻、20 Ω 变阻器。保持待测电阻不变，调节滑片记录多组 U、I，绘制 I-U 散点图。
- ⑫ 电流与电阻：6 V 电源、50 Ω 变阻器；待测电阻依次使用5、10、15、20 Ω，每次更换前断开开关。闭合后重新调节变阻器，将待测电阻两端电压恢复为2 V后记录（允许1%偏差）。电源电压不变不能代替控制待测电阻两端电压不变。合格的不同电阻数据保留在同组 I-R 图中，并保存每次接入的电阻值；换接线、测量对象或其他负载仍会分组。
- ⑬ 灯丝电阻：额定3 V、0.3 A的小灯泡，用稳态近似体现电压升高、电流增大、灯丝电阻增大及亮度变化。记录表和CSV增加电阻与功率；零电流时电阻显示为空，避免除零。不同工作状态的灯丝电阻不能求平均当作固定电阻。

灯丝模型用于定性教学，不是实测灯泡参数拟合，也不模拟升温、冷却或烧毁过程。定义额定电阻 Rr、额定电流 Ir，Ur=Ir×Rr；稳态 R(U)=Rr×[0.1+0.9×(|U|/Ur)^0.6]，冷态为额定电阻的1/10，额定电压处为额定电阻。与电路方程迭代求解后计算实际功率，维持原有固定电阻模型及旧文件的行为。模型选择、探究对象与控制电压支持JSON、自动保存和撤销。

新增 `node tests/inquiry-regression.cjs` 验证控制变量、分组、非线性伏安特性、额定工作点、功率、开断/低电压/反接、保存恢复；`node tests/browser-inquiry.cjs` 验证菜单、实际记录面板和新图像。

### 电路图网格对齐

电源、电阻、小灯泡、开关、变阻器、电流表、电压表、发光二极管、电动机、电铃共10类符号采用20单位网格接线柱。符号主体仍为原来的显示尺寸，引线绘制端点与实际连接点一致。新增、拖动、90°旋转、自动布局与独立电路分组摆放均使用整格坐标；非直角的旧符号在拖动或重新整理时按90°方向吸附，实物坐标与朝向规则保留。变阻器上下接线柱间隔80单位，固定端与滑片端的电流路径同步使用相同几何。

自动电路图路径的折点使用网格坐标；手动接线时，点击的途经点保留并补齐直角折点，预览与完成后的线路一致。已有文件的手动线路不主动重排，旧图需要整体对齐时点击“整理电路图”。图中元件过密时仍需要留出走线空间。

`node tests/grid-regression.cjs` 检查10类元件的四方向旋转、镜像、符号端点、13个实验布局与路径、分组平移、手动接线及实物坐标；`node tests/browser-grid.cjs` 使用实际鼠标逐个拖动并检查网格、旋转、后台整理与JSON恢复。

### 内置电路图与导线连接点

- 伏安法测电阻、电流与电压关系、电流与电阻关系共用规整的矩形电路图；并联电流、串联电压和并联电压实验各有专用布局。切换视图、整理电路图和 JSON 恢复会保留这些布局及后续手动调整。重新加载内置实验可恢复默认图。
- 在电路图的连线工具中，可从元件接线柱或已有导线开始画线，点击另一接线柱或已有导线完成连接。导线中间的连接会生成实心节点，参与电路计算，并随实验文件保存；完成整根连线前取消操作不会留下节点。
- 仅仅相交或拖动到重叠的导线不会自动连接。连接点可以选中移动或删除，删除节点会同时删除连接到它的线段。实物图仍使用仪器接线柱完成接线。
