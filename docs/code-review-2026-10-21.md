| 悬空支路可能获得弱电流资格 | 搜索允许绕到电源后沿原路返回，把“走过电源”误当闭合回路 | 按图的双连通边块识别包含电源的真实闭合回路，反向截止LED不提供通路 |

| 整理后控制点仍留在旧位置 | 清除了导线路径，未清除该视图的编辑状态 | 整理时同步清除当前视图的旧编辑状态，另一视图保留 |
| 反接故障恢复后曲线、控制点失配 | 备份只有折点，没有分视图编辑状态，临时重新布线仍带旧控制点 | 编辑状态随备份保存、校验、导出、导入和恢复；故障期间清除旧编辑状态 |
| 移出画布松开鼠标后仍在拖动 | 窗口mouseup只处理开关，未处理元件、控制点和平移 | 窗口统一完成拖动；触屏取消和双指切换也完成当前拖动 |
| 参数输入后无法自动保存 | 数值输入的HTML最小值不阻止键盘输入负电压或过大参数，保存校验却拒绝 | 电压和电阻赋值时按保存格式范围限制，并同步输入框 |

## 保持的物理与交互约定

灯泡仍采用固定电阻模型；电动机为等效电阻；电流表为理想零电阻；电压表内阻1 MΩ。箭头表示方向，疏密和速度不表示电流大小。理想导线闭环无法唯一分配各线电流时继续隐藏该连接网箭头并提示。手调线路发生碰撞时保留用户形状并提示；普通线路松开后只尝试局部修正。
